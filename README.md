# Lightsaber PropBoard

An open-source lightsaber controller board for a high-school club build. 18 x 90 mm, slides into 3/4 in PVC pipe.

- ESP32-C3, NS4168 I2S speaker amp, TP4056 Li-ion charger, LIS2DTW12 accelerometer
- Two WS2812 blade strips, one USB-C for charging and programming, soft-latch power button
- Designed in EasyEDA Pro, SMD assembly by JLCPCB; students solder only the JST connectors

Status: board design done (DRC clean), not ordered yet. Firmware not started. See [PROJECT-NOTES.md](PROJECT-NOTES.md).
